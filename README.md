# Exercices C - J2

Ce dépôt contient les exercices de programmation en C du module J2, répartis par dossiers.

## Contenu

- `ex-1/` à `ex-6/` : programmes C des exercices principaux.
- `ex-6-bonus/` : version bonus de l’exercice 6.
- `ex-recap-2/` : fichier d’énoncé de révision.
- `ex-recap-3/` et `ex-recap-4/` : exercices de révision en C.
- `recap-shell/` : document de révision lié au shell.

## Utilisation

Pour lancer un exercice, ouvrez le dossier correspondant, compilez le fichier `main.c` puis exécutez le binaire généré :

```bash
cd ex-1
./ex-1
```

Remplacez `1` par le dossier de l’exercice souhaité.
